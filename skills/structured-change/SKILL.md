# Structured Change
State **observable outcome, canonical owner, invariants and proof**. Inspect direct consumers/projections/tests and establish failing evidence for reproducible bugs when practical. Extend existing domain/evidence/storage/API owners; preserve fingerprint immutability, provenance, compatibility-before-ranking, credential privacy and Python semantic ownership. Use `validate-change` during implementation; `preflight-change` owns integration/release readiness.
